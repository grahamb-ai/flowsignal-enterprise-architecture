# FlowSignal™ Enterprise Architecture Publications

Welcome to the public technical publication library for **FlowSignal™** and the **Independent Runtime Authority Infrastructure (IRAI)**.

This repository contains the architectural, implementation and verification publications supporting the development of an independent Runtime Authority capable of determining whether delegated institutional authority remains legitimately exercisable immediately before consequential execution.

The publications are intended to support open technical discussion, independent architectural review and evidence-based engineering assessment.

---

# Publication Philosophy

The publications are organised into complementary document series.

Rather than presenting architecture as theory alone, the series progresses from:

```
Architectural Principles
        ↓
Reference Architectures
        ↓
Implementation
        ↓
Verification
        ↓
Independent Technical Review
```

This progression allows architectural concepts to be evaluated through observable implementation evidence rather than architectural assertion alone.

# Latest Publication

## IRAI-VERIFY-001 – Runtime Authority Verification Report

This report presents the first implementation verification of the FlowSignal™ Runtime Authority MVP.

The verification demonstrates:

- Independent Runtime Authority determination
- Execution Bind Point evaluation
- Runtime admissibility assessment
- Deterministic ALLOW and REFUSE decisions
- Authority Receipt generation
- Machine-readable evidence payloads
- Changed-condition verification
- Chronological decision traceability
- Implementation limitations and verification scope

The report has been intentionally limited to the current MVP implementation and should not be interpreted as a production-readiness assessment.

Its purpose is to provide **observable implementation evidence** supporting independent technical review.

# About FlowSignal™

FlowSignal™ is a reference implementation of the Independent Runtime Authority Infrastructure (IRAI).

Rather than replacing governance, workflow engines or AI platforms, FlowSignal operates immediately before consequential execution, independently determining whether delegated institutional authority remains legitimately exercisable under the current runtime conditions.

Runtime Authority therefore represents an execution-stage capability positioned between governance approval and consequence formation.

The publications within this repository describe architectural concepts, reference implementations and verification evidence.

- encourage constructive engineering feedback.

Unless explicitly stated, the publications should not be interpreted as product documentation, regulatory guidance or production deployment recommendations.
